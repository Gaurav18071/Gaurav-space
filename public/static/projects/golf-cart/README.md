# Golf Cart Project Assets

## Required Images

To complete the gallery for the Golf Cart project, add the following screenshot files to this directory:

1. **golf-cart-cover.jpg** ✓ (Already exists)
   - Current landing page hero
   - Size: 1024 x 466

2. **golf-cart-home.jpg** (TO ADD)
   - Full home page view with campaign highlights
   - Recommended size: 1920 x 1080
   - Should show: Hero section, featured campaigns, stats

3. **golf-cart-campaigns.jpg** (TO ADD)
   - Browse campaigns page
   - Recommended size: 1920 x 1080
   - Should show: Campaign grid, filters, search

4. **golf-cart-leaderboard.jpg** (TO ADD)
   - Leaderboard and statistics dashboard
   - Recommended size: 1920 x 1080
   - Should show: Top contributors, campaign rankings

5. **golf-cart-footer.jpg** (TO ADD)
   - Footer section with links and newsletter
   - Recommended size: 1920 x 1080
   - Should show: Footer links, social media, newsletter signup

## How to Capture Screenshots

1. Visit: https://golf-platform-gn.vercel.app/
2. Use browser DevTools to set viewport to 1920x1080
3. Take full-page screenshots or section screenshots
4. Save as JPG files with the names above
5. Place them in this directory

- Format: JPG (for photos/screenshots)
- Quality: 85-90% for good balance

- Keep file sizes under 500KB per image when possible
